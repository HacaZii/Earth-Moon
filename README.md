# Перелёт Земля — Луна 🌍 ➜ 🌕

Учебная браузерная игра на чистом HTML, CSS и JavaScript. Игрок выбирает силу и направление стартового импульса, запускает аппарат и корректирует траекторию в полёте. Цель — попасть в отмеченную область вокруг Луны, потратив как можно меньше времени и топлива (ΔV).

**Это упрощённая модель, а не реальный расчёт космического полёта.** Гравитация только от Земли и Луны, Луна неподвижна, орбиты плоские. Всё сделано для того, чтобы было интересно и понятно, а не физически точно.

---

## Как играть

1. Откройте `index.html` в браузере (или перейдите по ссылке на GitHub Pages).
2. Аппарат стоит **снизу от Земли**. Луна — справа. Вокруг Луны нарисована **пунктирная зелёная зона** — туда и нужно попасть.
3. Настройте стартовый импульс:
   - **Сила** — насколько сильно толкнуть аппарат.
   - **Угол** — `0°` означает «прямо к Луне»; положительные значения добавляют импульс «от Земли», чтобы компенсировать её притяжение.
4. Нажмите **«Запуск»**.
5. Если траектория уходит не туда — используйте **корректировки в полёте** (см. ниже).
6. Успех — аппарат входит в зелёную зону у Луны. Неудача — столкновение с Землёй, выход за границу карты или истечение времени полёта.

### Ориентиры для первого полёта

- Стартовая сила ≈ **7.0**, угол ≈ **0°** — аппарат полетит к Луне, но дуга загнётся вниз.
- Добавьте угол **+3…+8°** или увеличьте силу до **7.5–8.0**, чтобы скомпенсировать притяжение Земли.
- Слишком маленькая сила (≈ 3–5) — падение обратно на Землю.
- Слишком большая сила (≈ 9–10) и малый угол — пролёт мимо Луны или выход за границу карты.

Точное «идеальное» сочетание силы и угла ищите сами — это и есть задача пилота.

## Управление

### Компьютер (мышь и клавиатура)

| Действие | Как |
|---|---|
| Изменить силу стартового импульса | Слайдер «Сила» в панели «Стартовый импульс» |
| Изменить угол | Слайдер «Угол» |
| Запустить аппарат | Кнопка **«Запуск»** |
| Сбросить полёт | Кнопка **«Сброс»** |
| Скорректировать траекторию в полёте | Слайдеры «Сила» и «Направление» в панели «Корректировка» + кнопка **«Дать импульс»** |
| Приблизить / отдалить сцену | Колёсико мыши над сценой, либо кнопки **＋** / **−** справа сверху |
| Сбросить масштаб | Кнопка **⟲** справа сверху |
| Свернуть/развернуть телеметрию | Кнопка **☰** слева сверху |
| Скрыть весь интерфейс | Кнопка **⛶** слева сверху |
| Вернуть интерфейс | Кнопка **⛶** в правом нижнем углу |

### Телефон и планшет (Android, iOS)

| Действие | Как |
|---|---|
| Изменить силу / угол | Перетаскивание слайдеров пальцем |
| Запустить / сбросить | Кнопки **«Запуск»** / **«Сброс»** (крупные, под палец) |
| Корректировка в полёте | Слайдеры + кнопка **«Дать импульс»** |
| Масштаб сцены | **Пинч двумя пальцами** по сцене, либо кнопки **＋** / **−** |
| Свернуть телеметрию | Кнопка **☰** |
| Скрыть весь интерфейс | Кнопка **⛶** слева сверху, вернуть — **⛶** справа снизу |

Состояние «HUD свёрнут» и «интерфейс скрыт» запоминается между перезагрузками страницы.

## Правила

### Стартовый импульс
- Задаётся слайдерами до нажатия «Запуск».
- **Не тратит бюджет ΔV** — это выбор начальных условий, а не манёвр.

### Корректировки в полёте
- Каждая корректировка **мгновенно** меняет скорость аппарата на вектор, заданный силой и направлением.
- **Списывается из бюджета ΔV.** Бюджет — **2.0** (в тех же единицах, что и скорость).
- Когда бюджет исчерпан, кнопка «Дать импульс» становится неактивной.
- Если запрошенная сила больше остатка бюджета — применится только остаток.
- Направление `0°` — вправо (к Луне), `90°` — вверх по экрану, `−90°` — вниз.

### Условия победы и поражения

| Событие | Результат |
|---|---|
| Аппарат входит в зелёную зону вокруг Луны | **Успех** |
| Аппарат сталкивается с Землёй | Неудача: «Столкновение с Землёй» |
| Аппарат уходит за границу карты (радиус 400 у.е. от Земли) | Неудача: «Выход за границу карты» |
| Прошло больше 120 игровых секунд | Неудача: «Истекло время полёта» |

Столкновение и попадание в зону проверяются по **отрезку пути за шаг симуляции**, а не по конечной точке, поэтому аппарат не может «проскочить сквозь» Землю или Луну на большой скорости.

### Рекорды
- После успешного полёта сохраняются два рекорда:
  - **Лучшее время** — минимальное игровое время до попадания в зону.
  - **Лучший ΔV** — минимальные затраты на корректировки.
- Это два независимых рекорда: можно побить один, не побив другой.
- Хранятся в `localStorage` браузера — только у вас, между устройствами не синхронизируются.
- Сбросить рекорды можно кнопкой в экране итогов.

## Параметры симуляции (для любопытных)

Все константы — в начале `game.js`.

| Параметр | Значение | Смысл |
|---|---|---|
| `WORLD.earth.mass` | `400` | «Масса» Земли в условных единицах (гравитационный параметр) |
| `WORLD.earth.r` | `6` | Радиус Земли |
| `WORLD.moon.mass` | `25` | «Масса» Луны |
| `WORLD.moon.r` | `2.5` | Радиус Луны |
| `WORLD.moon.x` | `100` | Расстояние Земля—Луна (центр к центру) |
| `WORLD.moonZoneR` | `6` | Радиус зоны успеха вокруг Луны |
| `WORLD.startAlt` | `12` | Стартовая дистанция от центра Земли |
| `DV_BUDGET` | `2.0` | Бюджет ΔV на корректировки |
| `MAP_BOUND` | `400` | Радиус карты вокруг Земли |
| `DT` | `0.004` | Шаг интегрирования (velocity Verlet) |
| `TIME_SCALE` | `3` | 1 реальная секунда ≈ 3 игровые |
| `DIST_UNIT_LABEL` | `'у.е.'` | Подпись единиц расстояния |
| `DIST_UNIT_MULT` | `1` | Множитель для перевода в «км» (поставьте `3844` — получите километры) |

Гравитация считается по закону обратных квадратов от Земли и Луны. Интегрирование — velocity Verlet с фиксированным шагом.

Хотите «добрее» игру — уменьшите `WORLD.earth.mass` до `300` или увеличьте `WORLD.moonZoneR` до `8`.
